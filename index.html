Google ID Token Tester

Genera y decodifica un idToken de Google sin backend. Úsalo para probar login con Google, APIs que reciben idToken o tus propios guards.

1. Configura tu Client ID

OAuth Web client

Se guarda solo en localStorage de tu navegador. También puedes abrir la página con ?client_id=....

2. Inicia sesión con Google

Origen actual:

Este origen debe estar en Authorized JavaScript origins del Client ID. Sin slash final.

3. Tu idToken

El token se queda en tu navegador. No se envía a ningún servidor.

Cómo usarlo

  1. Obtén el idToken con el botón de Google.
  2. Envíalo a tu backend en POST /auth/google.
  3. Usa el accessToken que devuelva tu API.
curl -X POST http://localhost:3000/auth/google \
  -H 'Content-Type: application/json' \
  -d '{"idToken":"PEGA_EL_TOKEN"}'

Cambia la URL por la de tu API. Este proyecto no incluye backend.

Origen autorizado

  • Abre Google Cloud Console → Credentials.
  • Edita tu OAuth Client ID de tipo Web.
  • Agrega el origen actual en Authorized JavaScript origins.
  • Espera 1–2 minutos y recarga.

Abrir Google Cloud Console

Abriste la página con file://. Google no permite ese origen. Sírvela con un servidor local, por ejemplo: python3 -m http.server 5500, y abre http://localhost:5500.
